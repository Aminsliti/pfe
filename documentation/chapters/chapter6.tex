\label{tab:raffinement-vgrc}
\begin{tabular}{|p{3cm}|p{10.5cm}|}
\hline
\textbf{Field} & \textbf{Description} \\
\hline
Use Case & Integrate V-GRC System \\
\hline
Actor & V-GRC System, Administrator \\
\hline
Pre-condition & 
- System is running<br>
- V-GRC API connection is established<br>
- OAuth authentication is valid<br>
- Administrator is authenticated<br>
- Integration module is installed \\
\hline
Post-condition & 
- Data is exchanged bidirectionally between V-BPM and V-GRC successfully<br>
- Synchronization is configured and operational<br>
- Integration status is monitored and logged \\
\hline
Main Scenario Description & 
1. The system displays the V-GRC Integration Configuration page.<br>
2. The administrator views the current integration status and connection details.<br>
3. The administrator configures the V-GRC server URL and OAuth credentials.<br>
4. The administrator tests the connection and validates OAuth authentication.<br>
5. The system establishes secure connection with V-GRC using OAuth 2.0.<br>
6. The administrator configures synchronization frequency and data mapping rules.<br>
7. The system synchronizes risk data from V-BPM to V-GRC.<br>
8. The system receives internal controls and compliance indicators from V-GRC.<br>
9. The data is mapped and integrated into V-BPM with validation.<br>
10. A synchronization log is generated with success status and detailed metrics.<br>
11. The administrator can view connection status and recent synchronization logs. \\
\hline
Exceptions & 
- If connection fails, the system displays "Connection error to V-GRC API. Reconnection attempt in 5 minutes".<br>
- If OAuth authentication fails, an alert "Invalid OAuth credentials. Please verify configuration" is shown.<br>
- If synchronization fails, a message "Data synchronization failed. Check data format" is displayed.<br>
- If connection timeout occurs, the system shows "Timeout exceeded. V-GRC server is not responding".<br>
- If data mapping errors occur, an alert "Data mapping validation failed. Please check mapping rules" is shown.<br>
- If system/server error occurs, an error notification is displayed. \\
\hline
\end{tabular}
\end{table}
